### Reactive Android/Android Flows
## Run Locally

Clone the project

```bash
  git clone https://github.com/ulvinasirli99/RxAndroidAndKotlinFlow
```

Go to the project directory

```bash
  cd RxAndroidAndKotlinFlow
```

Run the project

```bash
  run the project
```

## Environment Variables

To run this project, you will need to add the following environment variables to your .env file and firstly you should create 'assets' folder inside of your main folder 

`TRADE_SECRET_KEY`

`TRADE_SOCKET_URL`

`TEACHER_BASE_URL`

Example : 

TRADE_SECRET_KEY=your_secret_key

TRADE_SOCKET_URL=your_base_trade_url

TEACHER_BASE_URL=your_free_test_api
